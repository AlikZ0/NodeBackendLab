# Node Backend Lab

Приложение на SwiftUI для iPhone и iPad с iOS 16+. В курсе 31 урок: 8 упражнений на JavaScript для API и 23 лабораторные с реальным Node.js. Теория, заготовки, подсказки, редактор и результаты проверок находятся в приложении. Черновики и прогресс сохраняются на iPhone.

Кнопки «Прослушать» и «Копировать» доступны для теории, задания, подсказки, кода, разбора и результатов проверки. Озвучка использует русский голос iOS.

## Как учиться без подключения к Ubuntu

В каждом уроке есть объяснение, ожидаемый результат и пример кода. Напиши свой вариант, открой «Разбор решения» и сравни с примером. Лабораторную можно отметить после самопроверки. Для проверки на компьютере нажми «Поделиться кодом с тестами», сохрани полученный текст в файл `lesson.mjs` и выполни `node lesson.mjs` на Node.js 24.

Восемь упражнений по JavaScript проверяются прямо на iPhone. Автоматический запуск лабораторных Node.js из приложения доступен через Ubuntu. На экране подключения есть кнопка «Проверить подключение».

| Раздел | Что сделаешь |
| --- | --- |
| Среда Node.js | Выведешь версии V8/libuv, создашь проект с npm-скриптом, разберёшь аргументы CLI, загрузишь модули ESM и CommonJS |
| Асинхронность и файлы | Проверишь порядок event loop, разберёшь URL и пути, напишешь файловый лог, обёртку над callback и счётчик слов |
| Процессы, события и потоки | Запустишь дочерний процесс и воркер cluster, подпишешься на EventEmitter, прочитаешь файл частями и сожмёшь его через pipeline |
| HTTP и фреймворк | Создашь HTTP-сервер, напишешь парсер JSON, роутер и middleware, соберёшь мини-фреймворк и проверишь его HTTP-запросами |
| База данных и итоговый проект | Выполнишь SQL-запросы и транзакции на SQLite, соберёшь API заметок и прогонишь интеграционные проверки |

За основу взята [публичная программа курса Ulbi TV](https://t.me/s/ulbi_tv?before=43). [Видео](https://www.youtube.com/watch?v=243pQXC5Ebs) можно смотреть параллельно. Для приложения написаны свои задания. В качестве базы используется SQLite из Node.js 24.

## Сборка с Ubuntu через GitHub

1. Распакуй архив. Создай на GitHub пустой репозиторий `NodeBackendLab` без README. В терминале Ubuntu открой распакованную папку `NodeBackendLab`.
2. Замени `USERNAME` именем своего аккаунта и отправь исходники на GitHub. Если Git запросит вход по HTTPS, используй авторизацию GitHub CLI или настроенный менеджер учётных данных.

   ```bash
   git init -b main
   git add .
   git commit -m "Add Node Backend Lab"
   git remote add origin https://github.com/USERNAME/NodeBackendLab.git
   git push -u origin main
   ```

3. Открой **Actions → iOS IPA**. Сборка стартует при первом push. Запуск вручную доступен через **Run workflow**. GitHub собирает приложение на macOS-раннере. Если сборка падает, открой лог шага **Build for iPhone**.
4. В успешном запуске скачай **NodeBackendLab-iOS** из **Artifacts** и распакуй ZIP. Внутри будет `NodeBackendLab.ipa`.

## Установка на iPhone

IPA из GitHub без подписи. Подпись выполняется при установке через SideStore. Apple ID и сертификаты в GitHub добавлять не нужно.

1. Установи SideStore на iPhone с Ubuntu по [официальной инструкции](https://docs.sidestore.io/docs/installation/install). Понадобятся USB-кабель, Apple Account, iLoader и LocalDevVPN. Если iOS запросит режим разработчика, включи его по инструкции.
2. Перенеси `NodeBackendLab.ipa` в «Файлы» на iPhone. Подключись к Wi-Fi, включи LocalDevVPN, открой SideStore → **My Apps → +** и выбери IPA.
3. При бесплатной подписи обновляй её в SideStore до истечения семи дней. Если SideStore уже установлен, начни с шага 2.

## Как запускать лабораторные из приложения

На Ubuntu понадобятся Node.js 20+ для запуска сервера и работающий Docker. Node.js 24 для самих лабораторных находится в контейнере.

```bash
node -v
npm -v
docker version
docker pull node:24-bookworm-slim
hostname -I
node Runner/server.mjs 192.168.1.30
```

Последний адрес замени на локальный IPv4 твоего Ubuntu. Подключи iPhone к той же доверенной Wi-Fi сети. В приложении открой «Подключить Ubuntu», введи адрес и одноразово сгенерированный код из терминала. Разреши приложению доступ к локальной сети, затем открой любую лабораторную и нажми «Проверить код». Новый запуск сервера создаёт новый код подключения.

Для каждого запуска создаётся контейнер без внешней сети, с отдельным временным каталогом, ограничениями памяти, процессов и времени. Внешний HTTP-сервер для лабораторных не нужен. Используй Ubuntu-исполнитель в своей локальной сети и не пробрасывай порт 4377 в интернет. Код передачи и ответы идут по локальному HTTP. На время практики отдельный сервер приложения должен оставаться запущен. Завершить работу можно через Ctrl+C.

Если iPhone не подключается, проверь адрес, разрешение «Локальная сеть», Wi-Fi и доступность TCP-порта 4377 на Ubuntu. Если в ответе ошибка Docker, проверь, что текущий пользователь может выполнить `docker version` и `docker image inspect node:24-bookworm-slim`.

## Дополнительный проект для терминала

Для практики подойдёт Node.js 20 или новее. npm-пакеты устанавливать не нужно. В `tasks.mjs` находятся заготовки. Команды для каждого этапа есть в уроках.

```bash
cd Practice
node -v
node --test --test-name-pattern=validation tasks.test.mjs
```

Первый тест ожидаемо падает, пока `normalizeTitle` возвращает `null` для всех входных данных. Выполни задание «Валидация запроса», затем запусти тест повторно. После реализации всех шести функций выполни `node --test`: тесты проверят функции и сделают настоящие HTTP-запросы.

Запусти `node server.mjs` в одном терминале. В другом создай задачу и запроси список.

```bash
curl -i -X POST http://127.0.0.1:3000/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Пройти урок Node.js"}'
curl -i 'http://127.0.0.1:3000/tasks?offset=0&limit=10'
```

Ожидаемые статусы — 201 и 200. Учебный сервер слушает только локальный адрес. Задачи живут в памяти до перезапуска.

После этого можешь развить API в портфолио: подключить PostgreSQL вместо массива, добавить PATCH и DELETE и написать для них интеграционные тесты.
